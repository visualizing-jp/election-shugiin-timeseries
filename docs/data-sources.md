# データソース

「衆議院選挙で、どの党がどれだけ票を得てきたか」のデータソース調査と、データ層の設計方針。
調査日: 2026-09-26。URL と表の中身は取得して確認済み。

## 1. 結論

一次情報源は総務省「衆議院議員総選挙・最高裁判所裁判官国民審査結果調」（政府統計コード `00200235`）。
e-Stat の時間軸付き統計表はなく、回ごとの冊子（Excel / PDF）である。

| 範囲 | 回 | 全国 | 都道府県（小選挙区）・ブロック（比例） |
| --- | --- | --- | --- |
| 小選挙区比例代表並立制 | 第41〜43回（1996–2003） | あり | なし |
| 同 | 第44〜51回（2005–2026） | あり | あり |

第41〜43回は、都道府県別・ブロック別の表を電子的に読める公式ファイルがない。

- 第41・42回: 総務省サイトにページがない。結果調は国立国会図書館デジタルコレクションの冊子スキャンだけ。
- 第43回: e-Stat の PDF（statInfId `000008255748`）は埋め込みフォントに文字の対応表がなく、テキストを取り出すと文字化けし、数字そのものが抜ける。

このため第41〜43回は、全国の党派別得票だけを「時代」ビューに載せる。

出典表記: 総務省「衆議院議員総選挙・最高裁判所裁判官国民審査結果調」。

### 確定と速報

総務省の各回のページは、どの回も「速報結果」の見出しで公開されている。確定結果は次のところにしかない。

- 第48・49回: [結果一覧](https://www.soumu.go.jp/senkyo/senkyo_s/data/shugiin/ichiran.html)の「確定結果」PDF
- 第44〜49回: e-Stat の PDF（第43回と同じく文字が取り出せない回がある）

第49回確定結果調の「党派別得票数の推移」（pp.25–26）には第22〜49回の全国の党派別得票がある。
第44〜49回の全国の総得票と自由民主党の得票を、この推移表の値と `npm run verify` で突き合わせ、一致を確認した。
このため第44〜49回を「確定」とし、確定結果が公表されていない第50・51回を「速報」とする。

## 3. 第41〜43回の手起こし

出典: [第49回確定結果調](https://www.soumu.go.jp/main_content/000930924.pdf) pp.25–26「党派別得票数の推移」。
`data/normalized/41.json`〜`43.json` が正本（`npm run normalize` は触らない）。

- 推移表は党名を略記する（自民、社民、新進、民主、民改連、さきがけ、自由、保守、無の会、自連、共産、公明）。
  次の正式名称に戻した: 自由民主党、社会民主党、新進党、民主党、民主改革連合、新党さきがけ、自由党、保守党、無所属の会、自由連合、日本共産党、公明党。第43回の保守新党は表に正式名称で載っている。
- 第42回小選挙区の民主党は、推移表では 16,811,782.222 だが、党の合計が「計」60,882,470.907 と 50 票ずれる。
  総務省「[政党助成法に基づく政党の届出の概要](https://www.soumu.go.jp/senkyo/seiji_s/data_seitou/2001/0918.html)」の 16,811,732.222 なら「計」と一致するので、こちらを採った。
- 第43回小選挙区の日本共産党は、推移表で「4,837,952,810」と桁区切りが崩れている。「計」との一致から 4,837,952.810 とした。
- 党の合計が「計」と一致することを `npm run verify` で確かめる。

## 4. 読み方の決まり

- 党名は各回の届出名称のまま。全角英数は半角に寄せ、空白と注記（※1）を除く。2行に折られた党名はつなぐ（第49回「NHKと裁判してる党弁護士法72条違反で」）。
- 別の回の同名・後継の党はつながない（民主党と立憲民主党、第48回と第49回の立憲民主党）。党名が同じ文字列の場合だけ同じ系列になる。
- 空欄・ダッシュ・0 は「その地域に候補（名簿）がない」として欠損。第49回の比例表は名簿のないブロックを 0 で埋めている。
- 按分票があるので小数第3位まで残す。
- 有効投票数は各表の「合計」列。得票率は得票数 ÷ 有効投票数。
- 第44回の PDF は `pdftotext -layout`（poppler）で読む。空欄は詰まるので、数値の右端の位置を見出しの位置と照らして列を決める。

## 5. 配信データ

`npm run data` が `data/normalized/*.json` だけを入力に、`public/data/` に書き出す。

| ファイル | 次元 | 値 |
| --- | --- | --- |
| `era.json` | 制度 × 回 × 党 | 得票数（全国）・有効投票数 |
| `pref.json` | 回 × 都道府県 × 党 | 得票数（小選挙区）・有効投票数 |
| `block.json` | 回 × ブロック × 党 | 得票数（比例代表）・有効投票数 |
